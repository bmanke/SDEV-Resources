- Added the **ReactJS Guide** as a subheading under Intermediate Frontend Development: an overview page and 18 original lessons that build one project, Filmshelf, from setup to deployment.
- The lessons cover components, JSX, props, state, events and forms, styling, conditional rendering, `useEffect`, `useRef`, `useContext`, `useReducer`, custom hooks, `memo`, `useCallback`, `useMemo`, React Router, Axios, TanStack Query, React Hook Form, Redux Toolkit, testing with Vitest, and deploying to GitHub Pages.
- Each lesson ends with practice problems and worked answers. The topics follow the roadmap in the ReactJS Guide from JSMastery.
- Added a **Resources** group to the sidebar, above the Changelog.
- Added the **ReactJS Guide (PDF)** page, with the PDF available to open or download. Credit: JSMastery, with a link to [jsmastery.com](https://jsmastery.com/).
- Added the **Emmet Cheatsheet** page. Credit: Jackson Beachell.
- The PDF is stored in `public/downloads/ReactJS-Guide.pdf`.
