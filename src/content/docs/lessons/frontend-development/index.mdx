A step-by-step path through plain JavaScript with Vite for SDEV-1150. Examples were run and tested, and every lesson ends with practice problems and worked answers.

## How to use these lessons

1. Go in order. Each lesson builds on the one before it.
2. **Type the examples yourself** instead of pasting them, and change them to see what breaks.
3. Do the "Check yourself" exercises before opening the answers.

## Lessons

| Lesson | What you will learn | Level | Time |
| ------ | ------------------- | ----- | ---- |
| [1. Tooling: Git, Node and Vite](/lessons/frontend-development/01-tooling-git-node-and-vite/) | Set up the tools every modern frontend project depends on, and learn the daily Git and npm workflow | Beginner | 12 min |
| [2. JavaScript Basics](/lessons/frontend-development/02-javascript-basics/) | Variables, data types, operators and the difference between == and === | Beginner | 13 min |
| [3. Control Flow and Functions](/lessons/frontend-development/03-control-flow-and-functions/) | Make decisions, repeat work and package behaviour into functions with if, loops and arrow functions | Beginner | 15 min |
| [4. Arrays and Objects](/lessons/frontend-development/04-arrays-and-objects/) | Store collections and records, then transform data with map, filter, find and reduce | Intermediate | 15 min |
| [5. The DOM: Selecting and Changing the Page](/lessons/frontend-development/05-the-dom/) | Find elements, change their content and styles, create new elements, and use timers | Intermediate | 16 min |
| [6. Events](/lessons/frontend-development/06-events/) | React to clicks, keys and input with listeners, and use propagation and delegation to scale up | Intermediate | 16 min |
| [7. Forms and Validation](/lessons/frontend-development/07-forms-and-validation/) | Collect user input with accessible forms, read it with FormData, and validate it with HTML and JavaScript | Intermediate | 16 min |
| [8. npm Packages and ES Modules](/lessons/frontend-development/08-npm-and-modules/) | Install libraries with npm, define scripts, and split your code into modules with import and export | Intermediate | 13 min |
| [9. REST APIs, fetch and CRUD](/lessons/frontend-development/09-fetch-and-rest-apis/) | Talk to a server with fetch and async/await, and build create, read, update and delete features | Intermediate | 20 min |
| [10. Web Components: Templates and Shadow DOM](/lessons/frontend-development/10-web-components-templates-and-shadow-dom/) | Build your own HTML elements with custom elements, templates, shadow DOM, slots and scoped styles | Advanced | 18 min |
| [11. Web Components: Properties, Lifecycle and Events](/lessons/frontend-development/11-web-components-properties-and-events/) | Make components configurable with attributes and properties, react to changes, and talk back with custom events | Advanced | 18 min |
| [12. Testing, Debugging and Deploying](/lessons/frontend-development/12-testing-debugging-and-deploying/) | Write automated tests with Vitest, find bugs with browser DevTools, and ship your app to the web | Advanced | 20 min |

About 3.2 hours of reading, plus the time you spend practicing.
