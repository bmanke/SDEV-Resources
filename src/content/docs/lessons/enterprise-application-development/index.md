This learning path breaks Enterprise Application Development into short, measurable lessons (usually 5–10 minutes each, with setup labs marked 10–15 minutes).

## Source acknowledgement

Topics are adapted from classroom sessions and slide/PDF materials from the **Northern Alberta Institute of Technology (NAIT)** Enterprise Application Development course sequence. This site provides original explanations and examples and does **not** redistribute original course files or imply institutional endorsement.

## How to use this path

1. Start at Module 1 and move in order.
2. Run each code sample locally in a small .NET console app or Blazor Web App.
3. Complete each practice task before expanding the answer.
4. Keep the long introduction page as optional background, not your primary route.

## Modules

- **Module 1:** C# Foundations for Application Work
- **Module 2:** SQL Import Safety and LINQPad Setup
- **Module 3:** LINQ with a Music Catalogue Fixture
- **Module 4:** Blazor UI Building Blocks
- **Module 5:** Workshop Domain, EF Core, and Business Rules
- **Module 6:** App State, Checkout Flow, and Security

> Fixtures used in this path are original: a small **music catalogue** for LINQ and a **Workshop** customer/parts/invoice domain for application lessons.
