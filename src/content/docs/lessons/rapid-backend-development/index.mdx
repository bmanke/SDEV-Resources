A step-by-step path through backend web development with Python and Django for SDEV-2401. Every lesson builds one piece of **Book Club**, a site where members browse books, librarians manage them, and members post reviews. The same data is then exposed as a REST API, tested and deployed. The code was assembled lesson by lesson, run against Django 5.2 and Django REST Framework, and covered by the test suite in lesson 15.

## Before you start

- Comfortable with Python functions, classes, modules and virtual environments (see Programming Fundamentals).
- Basic HTML. A little JavaScript helps for the API lessons, but is not required.
- Python 3.10 or newer and a code editor.

## How to use these lessons

1. Go in order. Each lesson changes the same project, and files shown in full replace the previous version.
2. **Type the examples yourself** instead of pasting them, and change them to see what breaks.
3. Run `python manage.py check` and the development server often. Read error pages from the bottom up.
4. Do the "Check yourself" exercises before opening the answers.

## The project at a glance

```text
Book Club
├── books/            models, forms, views, templates, REST API, commands, tests
├── accounts/         sign up (login and logout use Django's built-in views)
├── templates/        base layout, login and signup pages, 403 page
├── static/css/       site styles
└── bookclub/         settings and the root URL table
```
