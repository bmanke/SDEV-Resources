## What is inside

| Section | What it covers |
| ------- | -------------- |
| Introduction to React.js | What React is, who maintains it, and why it is so widely used |
| JavaScript prerequisites | The JavaScript you should know before starting React |
| The React.js roadmap | The basics, hooks, styling, UI frameworks, popular packages, state management, what to learn next, testing and deployment |
| Setup | Installing Node.js, an editor and Git |
| Core concepts | Components, JSX, props, state, events and hooks |
| Project ideas | 24 projects to build for your portfolio |
