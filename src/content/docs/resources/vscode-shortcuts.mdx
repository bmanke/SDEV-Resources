## Essential Core Commands

These general commands act as your main control center in VS Code:

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Open Command Palette (run any command) | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> |
| Quick Open (search and open files) | <kbd>Ctrl</kbd> + <kbd>P</kbd> | <kbd>Cmd</kbd> + <kbd>P</kbd> |
| Toggle Integrated Terminal | <kbd>Ctrl</kbd> + <kbd>&#96;</kbd> | <kbd>Ctrl</kbd> + <kbd>&#96;</kbd> |
| Toggle Side Bar (hide/show file explorer) | <kbd>Ctrl</kbd> + <kbd>B</kbd> | <kbd>Cmd</kbd> + <kbd>B</kbd> |

## Code Editing & Line Manipulation

Skip the mouse and manipulate entire lines of code at once:

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Move Line Up / Down | <kbd>Alt</kbd> + <kbd>&#8593;</kbd> / <kbd>&#8595;</kbd> | <kbd>Opt</kbd> + <kbd>&#8593;</kbd> / <kbd>&#8595;</kbd> |
| Duplicate Line Up / Down | <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>&#8593;</kbd> / <kbd>&#8595;</kbd> | <kbd>Shift</kbd> + <kbd>Opt</kbd> + <kbd>&#8593;</kbd> / <kbd>&#8595;</kbd> |
| Delete Line | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> |
| Toggle Line Comment | <kbd>Ctrl</kbd> + <kbd>/</kbd> | <kbd>Cmd</kbd> + <kbd>/</kbd> |
| Format Document (clean up indentation) | <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> | <kbd>Shift</kbd> + <kbd>Opt</kbd> + <kbd>F</kbd> |

## Search & Multi-Cursor Power Moves

Edit multiple lines simultaneously or jump to definitions instantly:

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| Insert Multi-Cursor | <kbd>Alt</kbd> + Click | <kbd>Opt</kbd> + Click |
| Add Cursor Above / Below | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>&#8593;</kbd> / <kbd>&#8595;</kbd> | <kbd>Cmd</kbd> + <kbd>Opt</kbd> + <kbd>&#8593;</kbd> / <kbd>&#8595;</kbd> |
| Select All Occurrences of Current Word | <kbd>Ctrl</kbd> + <kbd>F2</kbd> | <kbd>Cmd</kbd> + <kbd>F2</kbd> |
| Go to Definition (jump to functions/variables) | <kbd>F12</kbd> | <kbd>F12</kbd> |
| Find Text Across All Files | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> |
| Go to Symbol (jump to specific function in file) | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> |
