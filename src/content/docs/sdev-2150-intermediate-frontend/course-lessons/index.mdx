<Aside type="note" title="About these lessons">
These lessons cover the SDEV-2150 Intermediate Frontend Development course. They are written for this site, in their own words, and follow the same topic order as the course. The running project is **Campus Eats**, a directory of campus food spots, first built with Web Components and then rebuilt in React.
</Aside>

Every lesson adds one piece to **Campus Eats**, a directory of campus food spots with a search, category filters, a results list and a details card, backed by a small Express API. The project starts as a single vanilla HTML page, becomes a set of Web Components, then is rebuilt in React with Tailwind and DaisyUI. Routing, data loading, shared state and tests are added one lesson at a time.
