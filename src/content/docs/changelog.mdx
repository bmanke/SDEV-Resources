- Added a **Course Lessons** group to SDEV-2150 with 21 lessons, covering the course from the JavaScript and Web Components review through React, Tailwind, DaisyUI, state, routing, data, rendering strategies and unit testing.
- The lessons are written for this site in their own words, and follow the course's lesson numbering, including its gaps.
- Each lesson builds one piece of **Campus Eats**, a campus food spot directory, and ends with practice problems and answers.
- The Express API from the backend lesson was tested with `curl`, and the React project was built and exercised in a browser at each stage.
